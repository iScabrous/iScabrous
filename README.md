# Hi, I'm Nico 👋

**B.Sc. IuK Student @ FAU Erlangen-Nürnberg | Homelab & Tech Enthusiast**

I enjoy experimenting with home server virtualization, Linux systems, and automating my personal homelab with practical scripts and tools.

---

### 🚀 Projects & Hands-on Focus

- 🖥️ **Proxmox Homelab:** Running isolated LXC containers and Docker Compose stacks (Paperless-ngx, Immich, Vaultwarden, Home Assistant).
- 🔄 **CI/CD Automation:** Deploying and updating containers via GitHub Actions with a self-hosted runner on Proxmox.
- 🛡️ **Network & Privacy:** Remote access via Cloudflare Tunnels (no open router ports), local ad-blocking with AdGuard Home, and encrypted backups to Google Drive (Rclone).
- 📊 **Monitoring & Alerts:** Custom bash health scripts for host and container checks, sending push alerts to my phone via Home Assistant.
- 🌐 **Web Portfolio:** My personal CV and status dashboard hosted on Cloudflare Pages at [cv.nico-core.de](https://cv.nico-core.de).
